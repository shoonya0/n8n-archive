# _docs — everything about this repo

Start here when you sit down to work. Read in this order:

1. **[progress.md](progress.md)**: where things stand, what's next and open decisions.
2. **[how-to-build-a-project.md](how-to-build-a-project.md)**: the step-by-step process
   (superpowers + TDD) for any new workflow.
3. **[repo-overview.md](repo-overview.md)**: how the repo works: layout, commands, deploy,
   tests and n8n 2.x gotchas.
4. **[backlog.md](backlog.md)**: candidate projects, ranked, with a suggested first pick.

| Folder | What goes in it |
|---|---|
| [`specs/`](specs/) | Design docs from `superpowers:brainstorming`: `YYYY-MM-DD-<topic>-design.md` |
| [`plans/`](plans/) | Implementation plans from `superpowers:writing-plans`: `YYYY-MM-DD-<topic>-plan.md` |
| [`research/`](research/) | Background research the backlog is built from (read-only reference) |

**Keep it current:** at the end of every feature, update `progress.md` (done, next and
decisions) in the same branch as the feature.
